# ToothGrowth Explorer — Shiny and R Presenter

**Mrunmayi A Bhave**

Explore dose and supplement patterns in R's built-in ToothGrowth data. The app has reactive summaries, confidence intervals, a Welch test, a Plotly chart, and help built into its interface.

- [Open the live Shiny app](https://mrunmayiab.shinyapps.io/toothgrowth-explorer/)
- [Open the five-slide R Presenter pitch](https://mrunmayiab.github.io/R-Markdown-Presentation-Plotly---Developing-Data-Products/pitch.html)
- App source and novice instructions: [`toothgrowth_shiny_app/`](toothgrowth_shiny_app/README.md)
- Presentation source: [`pitch.Rmd`](pitch.Rmd)

Run locally with `shiny::runApp("toothgrowth_shiny_app")` after installing `shiny` and `plotly`.
